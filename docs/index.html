🤖 Zero-Touch Real-Time Mobile Automation

How real expense apps log live data without typing

Your Live Webhook Endpoint:
http://localhost:8080/api/webhook/payment

Accepts HTTP POST with raw notification text or JSON payload: {"text": "Paid Rs 250 to Subway..."}

🤖 Android (MacroDroid or Tasker - 2 Min Setup):
  1. Install free MacroDroid or Tasker from Google Play Store.
  2. Set Trigger: Notification Received → Select Google Pay, PhonePe, Paytm or SMS app.
  3. Set Action: HTTP Request (Method: POST, URL: your webhook, Body: {"text": "[not_text]"}).
• Result: Every single time you pay at a store or tap UPI, it logs into TraceEx within 500ms!
🍏 iOS (Apple Shortcuts Automation):
  1. Open the built-in Shortcuts app on your iPhone → tap Automation.
  2. Choose "When I receive a message from Bank" or "Transaction".
  3. Add Action: Get Contents of URL (POST to your TraceEx Webhook).
🏦 Production Open Banking / Account Aggregators:
For direct bank-to-bank API sync without notifications, enterprise apps use regulated Account Aggregators (like RBI-licensed Setu / Finvu in India or Plaid / Salt Edge in US/Europe) via approved developer credentials.
